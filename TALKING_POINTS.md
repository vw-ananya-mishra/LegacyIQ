## **ANTICIPATED JUDGE QUESTIONS & ANSWERS**

### **Q1: "Why should we trust AI for critical business logic?"**
**A:** "We don't. We use deterministic COBOL parsing to extract facts (no AI), then LLM validates recommendations against those facts. If LLMaaS fails, we fall back to Ollama or deterministic templates—never hallucinate. Plus, Parity Validator agent generates test scenarios proving functional equivalence."

### **Q2: "How does this compare to [competitor X]?"**
**A:** "Most competitors are point solutions—they either analyze code OR generate recommendations OR document. We're end-to-end: analysis → risk scoring → tech stack selection → proof-of-concept code → test scenarios → compliance documentation. Plus, we're COBOL-native; generic analyzers miss mainframe patterns."

### **Q3: "What's the actual ROI? €40.8M sounds optimistic."**
**A:** "It's based on VW's known COBOL portfolio (5K+ programs) and verified hourly rates (architect €100/hr, analyst €60/hr). Manual analysis = 40 hours per program. LegacyIQ = 2 seconds. The math is conservative—we're not assuming faster execution, just replacing manual hours with AI minutes."

### **Q4: "What if the COBOL is messy / undocumented?"**
**A:** "That's exactly our use-case. The parser works on raw COBOL syntax (no need for documentation). If the code is malformed, we flag warnings + show best-effort analysis. Even incomplete analysis beats zero analysis."

### **Q5: "How do you guarantee preservation of business logic?"**
**A:** "Parity Validator agent generates test scenarios (input/output pairs) from original logic. Modernized code must pass those tests. We also return original code side-by-side with modernized code, so human reviewers can verify construct-by-construct mapping."

### **Q6: "Can this work for other legacy languages (PL/SQL, FORTRAN, etc.)?"**
**A:** "Our framework is language-agnostic. COBOL parser is specialized, but we can extend to PL/SQL, FORTRAN, etc. The agent orchestration, dependency graph, risk analysis, and modernization recommendation logic all scale."

### **Q7: "Who would actually use this?"**
**A:** "Enterprises with large legacy portfolios: financial services (banking, insurance), automotive (VW, BMW, Daimler), retail (SAP systems), utilities (grid management). Anyone with 100+ COBOL programs + limited budget for modernization. VW is our primary design customer."

### **Q8: "What's the business model?"**
**A:** "B2B SaaS (cloud deployment) + on-premise (for regulated industries). Licensing per program analyzed (e.g., €10/program) or annual portfolio subscription. Even at €10/program, customer ROI is 800x (vs €8K manual cost per program)."
